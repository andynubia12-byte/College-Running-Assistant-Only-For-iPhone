GeoPilot 使用教程

iOS 虚拟定位桌面工具 — 连接 iPhone/iPad，实时模拟 GPS 位置

目录

1. 环境准备 2. 启动与连接设备 3. 场地配置 4. 矩形校准 5. 配速跑道 6. 随机游走 7. 路线回放 8. 配置管理 9. 开发者模式 10. 构建与部署 11. 常见问题

1. 环境准备

系统要求

  • Windows 10 / 11 x64
  • Python 3.11 或更高版本（仅开发模式需要）
  • iTunes 或 Apple 设备 USB 驱动

安装依赖（开发模式）

pip install -r requirements.txt

首次使用检查清单

  1. iPhone/iPad 已通过 USB 连接到电脑
  2. 设备已解锁，点击「信任此电脑」
  3. 设备已开启开发者模式（设置 → 隐私与安全性 → 开发者模式）
  4. 电脑有管理员权限（tunneld 需要创建虚拟网卡）
注意：首次连接设备时，iOS 会弹出"信任此电脑"对话框，必须点击「信任」才能继续。

2. 启动与连接设备

1
运行 python app.py（开发模式）或双击 GeoPilot.exe（打包版本）。
2
程序会自动检测 tunneld 是否运行。如果未运行，会弹出提示框询问是否启动。点击「确定」后弹出 UAC 提权窗口，点击「是」授权。
3
tunneld 启动后，首页状态卡的「Tunneld」指示灯变为绿色。
4
点击「刷新设备」，GeoPilot 扫描连接到电脑的 iOS 设备。发现的设备出现在设备列表中。
5
在设备列表中勾选需要控制的设备（支持多选），然后点击「连接选中」。
6
连接成功后，「设备」状态卡显示已发现和已选中的设备数量，指示灯变为绿色。底部的四个模式按钮变为可用状态。
提示：支持同时连接多台设备，勾选哪台就控制哪台。设备列表上方有「全选」复选框，可以一键选中/取消所有设备。

3. 场地配置

场地配置定义了矩形区域的四角 GPS 坐标。所有运行模式（配速跑道、随机游走、路线回放）都需要在指定的矩形区域内运行。

切换场地

在首页的「当前场地」下拉框中，选择已保存的场地预设。选项包括：

  • config.json (默认) — 主配置文件中的场地
  • 自定义预设 — 保存在 configs/ 目录下的 JSON 文件

导入场地配置

进入「设置」→「配置管理」，点击「导入场地」，选择一个 JSON 配置文件。如果文件名与已有预设冲突，会提示你重新命名。导入后自动切换为该预设。

导出场地配置

在设置页面点击「导出场地」，将当前配置保存为 JSON 文件。

4. 矩形校准

矩形校准是最关键的操作。你需要操控设备的 GPS 位置走到实际场地的四个角，系统保存坐标后生成矩形区域。

1
连接设备后，在首页点击「矩形校准」按钮进入校准页面。
2
点击「开始校准」。设备 GPS 自动跳转到默认起始位置（西北角）。
3
使用 W A S D 键或界面上的方向按钮微调位置，直到走到西北角的准确位置。
按键方向效果
W北 ↑纬度增加
S南 ↓纬度减少
A西 ←经度减少
D东 →经度增加
4
通过 + / - 按钮调整步长（1-100 米）。
5
到达准确位置后，点击「确认此角」。该角标记为已确认（绿色对勾），位置从上一个确认的角自动衔接，无需回到原点重来。
6
按顺序完成 NW → NE → SE → SW 四个角后，弹出保存对话框：
  • 保存到当前配置 — 写入当前激活的配置文件
  • 另存为新预设 — 创建新的场地预设文件，并自动切换为当前使用
  • 放弃 — 丢弃本次校准结果
技巧：步长设为 100m 可以快速移动，接近目标后逐步减小步长到 5m 或 1m 进行精确微调。

5. 配速跑道

在矩形区域内生成椭圆形跑道，按指定配速模拟跑步运动。适合模拟操场跑步、马拉松训练等场景。

参数说明

参数范围说明
配速2.0 - 15.0 min/km每公里用时，数值越小跑得越快
时长60 - 36000 秒模拟运行的总时长
抖动0 - 20 米GPS 位置随机偏移，模拟真实定位误差
提示：跑道会自动适应矩形区域。如果矩形宽大于高，跑道沿水平方向伸展；反之沿垂直方向。跑道大小还会在每圈随机变化（60%-100%），增加真实感。

6. 随机游走

在矩形区域内模拟随机移动路径，碰到边界后反弹。适合模拟行人逛街、散步等场景。

参数说明

参数范围说明
速度0.5 - 20.0 m/s移动速度
时长60 - 36000 秒模拟运行的总时长
抖动0 - 20 米GPS 位置随机偏移
方向变化0.5 - 45.0 deg方向变化的标准差，值越大路径越随机

7. 路线回放

导入 GPX 或 JSON 格式的路线文件，按路径点顺序回放移动轨迹。适合模拟沿特定路线跑步、骑行等场景。

支持的路线格式

  • JSON — 包含 route_name 和 coordinates 数组的 JSON 文件
  • GPX — 标准 GPX 格式，使用 python import_gpx.py 转换为内部格式

参数说明

参数范围说明
循环圈数1 - 9999路线重复播放的次数

导入 GPX 路线

python import_gpx.py path/to/route.gpx --output routes/my_route.json

8. 配置管理

所有配置参数都可以在「设置」页面统一管理。设置页面的「配置管理」区域位于最顶部，提供完整的预设管理功能。

预设列表

显示所有可用的场地预设。点击列表中的预设名称即可切换为当前使用。

按钮说明

按钮功能
导入场地从外部 JSON 文件导入为新的场地预设
导出场地将当前配置导出为 JSON 文件
删除选中删除在列表中选中的预设
保存当前配置保存所有参数到当前激活的配置文件
另存为预设将当前参数保存为新的场地预设
恢复默认将所有参数恢复为出厂默认值

通用设置

参数说明
定位间隔每次 GPS 更新之间的间隔（秒）
抖动范围全局 GPS 抖动幅度（米）
中点概率在路径点之间插入中点的概率
默认圈数路线回放的默认循环圈数

9. 开发者模式

iOS 16+ 设备需要开启开发者模式才能使用虚拟定位功能。设置页面提供三个操作：

  1. 检查状态 — 查询当前设备是否已开启开发者模式
  2. 显示开发者选项 — 让开发者模式开关出现在设备设置中（不会重启），然后手动前往 设置 → 隐私与安全性 → 开发者模式 开启
  3. 完全激活 — 直接激活开发者模式（设备会重启，需确保设备没有锁屏密码）
警告：「完全激活」会导致设备重启，请确保设备没有设置锁屏密码，否则重启后可能无法自动解锁。

10. 构建与部署

开发模式运行

python app.py

CLI 模式（遗留）

python main.py --mode pace --duration 1800 --udid <设备UDID>

手动启动 tunneld

python -m pymobiledevice3 remote tunneld

打包为可执行文件

pyinstaller geosim.spec --clean --noconfirm

输出目录：dist/GeoPilot/

创建安装包

build.bat

生成三个分发文件：

  • dist/GeoPilot/ — 绿色免安装版
  • dist/GeoPilot_portable.zip — 便携版压缩包
  • dist/GeoPilot_setup.exe — SFX 安装包

11. 常见问题

Q: tunneld 启动失败或端口被占用？

端口 49151 可能被其他进程占用。运行以下命令查找并终止占用进程：

netstat -ano | findstr 49151
taskkill /PID <进程ID> /F

Q: 设备列表中看不到我的 iPhone/iPad？

  1. 确认 USB 数据线支持数据传输（不是仅充电线）
  2. 确认设备已解锁并点击了「信任此电脑」
  3. 确认 iTunes 或 Apple USB 驱动已安装
  4. 点击「刷新设备」重新扫描

Q: 虚拟定位不生效？

  1. 确认设备已开启开发者模式
  2. 确认「设置 → 隐私与安全性 → 开发者模式」已打开
  3. 检查是否有其他定位模拟工具在运行（Xcode 等）
  4. 在设备上打开地图应用验证位置

Q: 校准后跑道/游走提示"未设置矩形区域"？

校准完成后需要在保存对话框中选择「保存到当前配置」或「另存为新预设」，仅点击「放弃」不会保存。

Q: 导入的场地配置为什么没有生效？

导入场地配置后会自动切换为该预设。如果其他页面没有更新，切换到对应页面时会自动重新加载配置。如果仍不生效，请检查预设文件是否包含完整的 random_walk.corners 字段。

Q: 打包后的程序在干净虚拟机上运行报错？

最常见的原因是缺少 wintun.dll 或 Python 模块未完全打包。确认 geosim.spec 中包含了 wintun.dll 和所有 hiddenimports。如果仍有问题，查看 build/geosim/warn-geosim.txt 中的缺失模块警告。
